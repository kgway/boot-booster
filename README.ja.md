# Boot Booster

[English](README.md)

大量のノートがあるAndroidのObsidianで、起動時の処理を減らすプラグインです。保存したファイル一覧を再利用し、背景で実ファイルを確認しながら、ノートを開く操作を優先します。

## 導入・更新

コミュニティへの登録は申請前です。掲載までは [GitHub Releases](https://github.com/kgway/boot-booster/releases) から手動で導入できます。

1. Vaultをバックアップし、Obsidianを終了します。
2. 同じリリースの `main.js`・`manifest.json`・`styles.css` をダウンロードし、Vault内の `.obsidian/plugins/boot-booster/` に置きます。
3. Obsidianを開き直し、コミュニティプラグインの設定でBoot Boosterを有効にします。

更新時は本体3ファイルだけを置き換え、既存の `data.json` を保持してください。GitHubの **Source code** は開発用ソースで、導入用ではありません。`INSTALL.md` は試用ZIPの案内として使い、正式リリースには添付しません。

ファイル一覧の高速化は **Android版Obsidian API 1.13.8 / 1.14.4** に対応しています。それ以外の版では通常の読み込みを使います。初回は通常の一覧を記録します。「自動」は、前回の通常読み込みが2.5秒以上、対象が1,000項目以上の場合に一覧を再利用します。アプリ更新後は速度を測り直します。

## 設定

最上部の「起動状態」で現在の作業、進捗、待機理由、起動時間の比較を確認できます。「起動記録」は直近5回を表示し、「すべて表示」で同じ表に続きを並べます。コピーと消去はJSONを閉じていても使えます。

初期表示はObsidianが日本語なら日本語、それ以外なら英語です。設定の途中にある「言語」で切り替えると、すぐに反映されます。この選択は端末内に保存します。

隠れたタブは開いたときに読み込みます。起動時にどのノートを開くかはObsidianに任せます。Androidでは、サイズを記録済みの512Ki文字以上のプラグイン本体を高速な経路で読み込めます。コードは毎回読み取り、ほかのプラグイン同士の実行順序は保ちます。「タブプレビューの省略」は任意で、初期設定はオフです。

## 保存するデータと計測

ノート本文はキャッシュしません。一覧、タブの表示情報、プラグイン本体のサイズ、直近20回の起動記録を端末内に保存します。Androidの高速読み取りが通信する先はlocalhostのみです。外部サービスへの送信と自己更新は行いません。

起動記録のJSONにVault名・本文・ノートのパスは含めません。旧版の記録にはユーザーが入力したラベルが残る場合があります。時間はWebViewの開始を基準とした観測値で、アプリ自体の起動時刻からの時間ではありません。処理の時間は重なるため合計できません。条件が合う通常起動の記録があれば比較を表示しますが、同じ起動で高速化しなかった場合の時間を予測するものではありません。

## 確認と復旧

再利用した一覧は、実ファイルとの確認が終わるまで暫定です。開くノートを先に確認し、書き込み前には毎回確認します。書き込み前の確認中や移動先の確認中に変更を検出した場合は、その操作を止めます。確認中のフォルダ削除・移動・コピーも止めます。検索・Graph・クエリ結果は確認中には不完全な場合があり、他プラグインの索引更新はその後も続くことがあります。

確認に失敗した場合は保護を残します。「ファイル一覧の高速化」を「使わない」にしてObsidianを再起動してください。以前の版へ戻す場合はObsidianを終了し、バックアップした本体3ファイルを戻して `data.json` を保持します。外部アプリの同時書き込みを排他制御するものではありません。

Obsidianの内部APIを使用します。アプリ更新や他プラグインによって動作が変わる可能性があり、未検証のファイル一覧APIでは通常の読み込みに戻します。合成データを使ったエミュレータでの検証範囲は [試験について](docs/testing.md) を参照してください。実機での性能、同期、IME、独自テーマを網羅的に検証したものではありません。

不具合は [GitHub Issues](https://github.com/kgway/boot-booster/issues) へ、Obsidianの版・端末の種類・再現手順とともに報告してください。起動記録を共有する場合は、旧版のラベルなどを確認してから貼り付けてください。

## 開発

Node.js 24.19以降と `package.json` に指定された版のpnpmを使います。

```sh
pnpm install --frozen-lockfile
pnpm check
pnpm test
pnpm lint
pnpm build
pnpm check:release
```

公式Obsidian lintのエラー・警告をすべて検査します。CIの成功とコミュニティ審査の完了は別です。手動実行するリリース用ビルドは、指定したソースのコミットと本体3ファイルのハッシュを確認し、成果物とビルド証明を作ります。リリースを自動公開する処理はありません。[配布用ビルド](docs/releasing.md) を参照してください。

UI文言は [ja.json](src/locales/ja.json) と [en.json](src/locales/en.json) にまとめています。日本語を編集して英語を合わせる手順は [文言の編集](docs/editing-text.md) を参照してください。
